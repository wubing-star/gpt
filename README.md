# TikTok Shop 销量雷达采集器

云端直接读取 TikTok Shop 店铺商品，并将真实快照提交到私有雷达网页。

- 运行中的采集进程每五分钟读取一轮，按实际采样时间计算滚动两小时增量。
- 每段进程在到期前通过 GitHub 官方 workflow_dispatch 接力；整点以外的小时定时任务作为故障恢复入口。任务启动和接力仍可能受到 GitHub 排队延迟影响。
- 同一时刻只有一个采集进程持有数据库租约；运行状态根据真实心跳和快照显示。
- 网页“立即采集”提交请求，由在线采集进程接收，网页关闭不影响后台。
- 监控店铺名单从私有站点读取，站点凭据保存在 Actions Secret `RADAR_SITE_TOKEN`，不写入代码或日志。
- 累计已售计数包含退货，不等于净成交订单数；历史窗口缺失时不推算销量。

## 暂停与恢复

在 GitHub Actions 中禁用此工作流，并取消正在执行的任务，可停止后续采集。恢复时启用工作流并手动运行一次。

当前先验证已导入的店铺；可保存最多 200 家店铺，实际采集容量须逐步验证。
